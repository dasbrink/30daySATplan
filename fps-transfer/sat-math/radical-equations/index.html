Solving Radical Equations

SAT Math · Advanced Math · Updated October 2026

Where I would start

Get the square root alone on one side, square both sides, and solve. Then check every answer in the original equation. Squaring can create answers that do not work, because a square root is never negative.

If the radical ends up equal to a negative number, stop: there is no solution.

The SAT asks you to solve radical equations, to find a constant from a given solution, to count the solutions, and to spot the extraneous one. Cube roots and fractional exponents show up too.

Reading the concept isn't enough. The score comes from practicing in the real digital SAT format and finding the exact mistakes you keep making.

What the SAT tests here

StepWhat to do
1. Isolate the radicalMove everything else to the other side before squaring. Squaring $\sqrt{x} + 3$ as a whole creates a messy cross term.
2. Square both sidesSquare the whole side: $(x - 5)^2 = x^2 - 10x + 25$, not $x^2 - 25$.
3. SolveThe result is usually linear or quadratic.
4. CheckSubstitute each answer into the original equation. Reject any that make the two sides differ.
Cube rootsCube both sides. Cube roots can be negative, so cubing never creates extraneous answers.
Fractional exponents$x^{\frac{1}{2}} = \sqrt{x}$ and $x^{\frac{3}{2}} = \left(\sqrt{x}\right)^3$. To undo an exponent of $\dfrac{3}{2}$, raise both sides to $\dfrac{2}{3}$.

How to solve one, step by step

Example 1: finding a constant

The equation $\sqrt{3x + k} - 2 = 5$ has the solution $x = 6$. What is $k$?

  1. Substitute $x = 6$: $\sqrt{18 + k} - 2 = 5$.
  2. Isolate the radical: $\sqrt{18 + k} = 7$.
  3. Square: $18 + k = 49$, so $k = 31$.

Example 2: an extraneous solution

Solve $\sqrt{x + 7} = x - 5$.

  1. Square both sides: $x + 7 = x^2 - 10x + 25$.
  2. Rearrange: $x^2 - 11x + 18 = 0$, so $(x - 2)(x - 9) = 0$ and $x = 2$ or $x = 9$.
  3. Check $x = 2$: $\sqrt{9} = 3$, but $2 - 5 = -3$. It fails.
  4. Check $x = 9$: $\sqrt{16} = 4$ and $9 - 5 = 4$. The only solution is $x = 9$.

Example 3: no solution at a glance

Solve $\sqrt{2x - 1} + 3 = 0$.

  1. Isolate the radical: $\sqrt{2x - 1} = -3$.
  2. A square root is never negative, so no value of $x$ works.
  3. If you square anyway, you get $x = 5$, and the check shows $\sqrt{9} + 3 = 6$, not $0$.

Example 4: a cube root

Solve $\sqrt[3]{x - 4} = 3$.

  1. Cube both sides: $x - 4 = 27$.
  2. $x = 31$. Check: $\sqrt[3]{27} = 3$.
  3. A cube root can equal a negative number, so $\sqrt[3]{x - 4} = -3$ would have the solution $x = -23$.

The mistakes that cost points

  • Squaring before isolating the radical. Squaring $\sqrt{x} + 3 = 7$ as it stands gives a harder equation. Subtract $3$ first.
  • Squaring a binomial term by term. $(x - 5)^2$ is $x^2 - 10x + 25$. The middle term is easy to forget.
  • Skipping the check. The SAT almost always lists the extraneous answer as a choice.
  • Allowing a square root to be negative. $\sqrt{x} = -4$ has no solution. Only cube roots and other odd roots can be negative.
  • Mishandling fractional exponents. If $x^{\frac{3}{2}} = 27$, then $x = 27^{\frac{2}{3}} = 9$, not $27 \cdot \dfrac{2}{3}$.

  • B$18$
