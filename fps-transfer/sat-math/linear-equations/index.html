Solving Linear Equations on the SAT

SAT Math · Algebra · Updated October 2026

Where I would start

Solve a linear equation by undoing what was done to $x$, in reverse order, doing the same thing to both sides each time. Clear parentheses and fractions first, gather the $x$ terms on one side, then divide.

The SAT adds two twists: a constant like $k$ that you find by substituting the given solution, and questions about whether an equation has one solution, no solution, or infinitely many.

Linear equations are the most common question type in SAT Math. Most are quick, so the points are lost to small slips: a sign dropped while distributing, a fraction not cleared from every term, or solving for $x$ when the question asked for something else.

Reading the concept isn't enough. The score comes from practicing in the real digital SAT format and finding the exact mistakes you keep making.

What the SAT tests here

You seeDo this
ParenthesesDistribute first, including any minus sign: $-2(x - 4) = -2x + 8$.
FractionsMultiply every term on both sides by the least common denominator.
$x$ on both sidesMove all $x$ terms to one side and all numbers to the other.
A constant $k$ and a given solutionSubstitute the solution for $x$, then solve for $k$.
"How many solutions?"Simplify to $ax + b = cx + d$. If $a \neq c$: one solution. If $a = c$ and $b \neq d$: no solution. If $a = c$ and $b = d$: infinitely many.
"What is the value of $2x - 3$?"Look for that expression inside the equation before solving for $x$. It is often a single step away.

How to solve one, step by step

Example 1: finding a constant

The equation $5(x + k) - 5 = 20$ has the solution $x = 3$. What is $k$?

  1. Substitute $x = 3$: $5(3 + k) - 5 = 20$.
  2. Add $5$: $5(3 + k) = 25$. Divide by $5$: $3 + k = 5$.
  3. $k = 2$.

Example 2: clearing fractions

Solve $\dfrac{x}{3} + \dfrac{x}{4} = 7$.

  1. The least common denominator is $12$. Multiply every term by $12$: $4x + 3x = 84$.
  2. $7x = 84$, so $x = 12$.
  3. Check: $\dfrac{12}{3} + \dfrac{12}{4} = 4 + 3 = 7$.

Example 3: no solution or infinitely many

For what value of $k$ does $3(2x - 1) = 6x + k$ have infinitely many solutions?

  1. Distribute: $6x - 3 = 6x + k$.
  2. The $x$ terms already match on both sides. If the constants match too, every $x$ works.
  3. So $k = -3$. Any other value of $k$ gives no solution at all.

Example 4: solving for an expression

If $4x - 6 = 10$, what is the value of $2x - 3$?

  1. Notice that $4x - 6$ is exactly $2(2x - 3)$.
  2. So $2(2x - 3) = 10$, and $2x - 3 = 5$.
  3. Solving for $x$ first ($x = 4$) also works, but it takes longer and gives you one more chance to slip.

The mistakes that cost points

  • Distributing a minus sign to only the first term. $-3(x - 2)$ is $-3x + 6$, not $-3x - 6$.
  • Clearing fractions from only some terms. When you multiply by the denominator, every term on both sides gets multiplied, including whole numbers.
  • Answering with $x$ when the question asks for something else. Read the last line again before you choose an answer.
  • Mixing up "no solution" and "infinitely many". Same $x$ terms with different constants means no solution. Same $x$ terms and same constants means infinitely many.
  • Sign slips when moving terms. Moving $+7$ across the equals sign makes it $-7$. Doing the same operation to both sides avoids this.

Medium
In the equation $3x + 22 = kx + 4$, $k$ is a constant and $k \neq 3$. Which expression gives $x$ in terms of $k$?
  • A$\dfrac{18}{3 - k}$
  • B$\dfrac{26}{k - 3}$
  • C$-\dfrac{18}{k + 3}$
  • D$\dfrac{18}{k - 3}$
Show solution
Answer: D. Move the $x$ terms to one side: $3x - kx = 4 - 22$, so $x(3 - k) = -18$. Then $x = \dfrac{-18}{3 - k}$. Multiplying the top and bottom by $-1$ gives $\dfrac{18}{k - 3}$. Choice A drops the minus sign.

  • BInfinitely many
  • CZero
  • DExactly two
Show solution
Answer: B. Simplify each side. Left: $4x - 8 + 3 = 4x - 5$. Right: $4x - 2 - 3 = 4x - 5$. The two sides are identical, so every value of $x$ works.

  • B$0$

Answer: C. With $a = 3$, the equation becomes $3x + 5 = 3x - 2$, which simplifies to $5 = -2$. That is never true, so there is no solution. Any other value of $a$ gives exactly one solution.
