Parallel and Perpendicular Lines on the SAT

SAT Math · Algebra · Updated October 2026

Where I would start

Everything here comes down to slope. Parallel lines have the same slope. Perpendicular lines have slopes that are negative reciprocals: flip the fraction and change the sign, so $\dfrac{2}{3}$ becomes $-\dfrac{3}{2}$. Their product is always $-1$.

So the first step is always the same: get the slope of the line you are given. If it is written as $Ax + By = C$, rewrite it in the form $y = mx + b$, or use the shortcut $m = -\dfrac{A}{B}$.

These questions are short, but they hide two traps: forgetting to change the sign when finding a perpendicular slope, and reading the slope straight off an equation that is not in slope-intercept form.

Reading the concept isn't enough. The score comes from practicing in the real digital SAT format and finding the exact mistakes you keep making.

The blue lines $y = 2x + 1$ and $y = 2x - 4$ have the same slope, so they are parallel. The red line $y = -\dfrac{1}{2}x + 1$ has slope $-\dfrac{1}{2}$, the negative reciprocal of $2$, so it is perpendicular to both.

How to solve one, step by step

Example 1: a parallel line through a point

Find the line parallel to $y = -2x + 5$ that passes through $(3, 1)$.

  1. Parallel means the same slope: $m = -2$.
  2. Use the point: $y - 1 = -2(x - 3)$, so $y - 1 = -2x + 6$.
  3. $y = -2x + 7$. Check: $-2(3) + 7 = 1$.

Example 2: a perpendicular line from standard form

Find the line through the origin that is perpendicular to $2x + 5y = 10$.

  1. Slope of the given line: $-\dfrac{A}{B} = -\dfrac{2}{5}$.
  2. Negative reciprocal: $\dfrac{5}{2}$.
  3. Through the origin, the $y$-intercept is $0$: $y = \dfrac{5}{2}x$.

Example 3: finding a constant

The lines $3x + ky = 7$ and $6x - 2y = 5$ are parallel. Find $k$.

  1. Slope of the second line: $-\dfrac{6}{-2} = 3$.
  2. Slope of the first line: $-\dfrac{3}{k}$.
  3. Set them equal: $-\dfrac{3}{k} = 3$, so $k = -1$.

The mistakes that cost points

  • Flipping without changing the sign. Perpendicular to slope $\dfrac{2}{3}$ is $-\dfrac{3}{2}$, not $\dfrac{3}{2}$.
  • Changing the sign without flipping. $-\dfrac{2}{3}$ is not perpendicular to $\dfrac{2}{3}$. You need both steps.
  • Reading the slope from standard form. In $2x + 5y = 10$ the slope is not $2$. It is $-\dfrac{2}{5}$.
  • Calling identical lines parallel. Same slope and same intercept is one line with infinitely many solutions, not two parallel lines.
  • Sign slips with the point. Through $(8, -1)$, the point-slope form is $y + 1 = m(x - 8)$.

Show solution
Answer: $2$. Line $\ell$ has slope $\dfrac{8 - 2}{4 - 1} = 2$, so line $n$ has slope $-\dfrac{1}{2}$. Then $\dfrac{a - 5}{6 - 0} = -\dfrac{1}{2}$, so $a - 5 = -3$ and $a = 2$.
Hard
Line $m$ is perpendicular to the line $y = -\dfrac{3}{4}x + 2$ and passes through the point $(8, -1)$. What is the $y$-intercept of line $m$?
  • A$-\dfrac{35}{3}$
  • B$\dfrac{29}{3}$
  • C$-1$
  • D$\dfrac{35}{3}$
Show solution
Answer: A. The slope of line $m$ is $\dfrac{4}{3}$. $y + 1 = \dfrac{4}{3}(x - 8)$. At $x = 0$: $y = -1 - \dfrac{32}{3} = -\dfrac{35}{3}$. Choice B adds $\dfrac{32}{3}$ instead of subtracting it.

Each system below includes the equation $y = 2x + 3$. Which system has no solution?
  • A$y = 2x + 3$ and $4x - 2y = -6$
  • B$y = 2x + 3$ and $2x + 4y = 6$
  • C$y = 2x + 3$ and $4x - 2y = 6$
  • D$y = 2x + 3$ and $y = 3x + 2$
Show solution
Answer: C. $4x - 2y = 6$ becomes $y = 2x - 3$: same slope, different intercept, so the lines are parallel and never meet. Choice A becomes $y = 2x + 3$, the same line, so it has infinitely many solutions.
Hard
Which line is perpendicular to the line $y = \dfrac{3}{4}x + 1$?
  • A$3x - 4y = 8$
  • B$3x + 4y = 12$
  • C$4x - 3y = 12$
  • D$4x + 3y = 12$
Show solution
Answer: D. Perpendicular needs slope $-\dfrac{4}{3}$. For $4x + 3y = 12$, the slope is $-\dfrac{4}{3}$. Choice A has slope $\dfrac{3}{4}$ (parallel), and choice C has slope $\dfrac{4}{3}$ (sign not changed).
