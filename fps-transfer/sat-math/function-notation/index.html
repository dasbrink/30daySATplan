Function Notation on the SAT

SAT Math · Advanced Math · Updated October 2026

Where I would start

$f(x)$ is not $f$ times $x$. It is the output of the function $f$ when the input is $x$. So $f(4)$ means: put $4$ in for every $x$ and work out the result.

Read each question for which side you know. "Find $f(4)$" gives you the input and asks for the output. "$f(a) = 19$, find $a$" gives you the output and asks for the input, so you set up an equation and solve it.

Function notation shows up all over SAT Math, in algebra questions, in word problems and in graphs. The math inside is usually easy. Points are lost by mixing up inputs and outputs, or by substituting into only some of the $x$'s.

Reading the concept isn't enough. The score comes from practicing in the real digital SAT format and finding the exact mistakes you keep making.

What the SAT tests here

You seeDo this
$f(4)$Replace every $x$ with $4$, in parentheses, and evaluate.
$f(a) = 19$Set the rule equal to $19$ and solve for $a$.
$f(2a)$ or $f(x + 1)$Replace every $x$ with the whole expression, in parentheses, then simplify.
A constant in the rule, plus one known valueSubstitute the known input and output to find the constant first.
$f(g(2))$Work from the inside out: find $g(2)$, then put that number into $f$.
"What does $p(25) = 340$ mean?"The input is $25$ of something and the output is $340$ of something else. Name both with their units.

How to solve one, step by step

Example 1: input given, find the output

If $g(x) = x^2 - 2x + 1$, what is $g(-3)$?

  1. Put $-3$ in parentheses everywhere $x$ appears: $g(-3) = (-3)^2 - 2(-3) + 1$.
  2. $(-3)^2 = 9$ and $-2(-3) = 6$, so $g(-3) = 9 + 6 + 1 = 16$.

Example 2: output given, find the input

If $f(x) = 2x + 7$ and $f(a) = 19$, what is $a$?

  1. $f(a) = 2a + 7$, so $2a + 7 = 19$.
  2. $2a = 12$, and $a = 6$.
  3. Check: $f(6) = 12 + 7 = 19$.

Example 3: finding a constant

For $f(x) = ax^2 + 5$, $f(2) = 17$. What is $f(-3)$?

  1. Use the known value: $a(2)^2 + 5 = 17$, so $4a = 12$ and $a = 3$.
  2. Now the rule is $f(x) = 3x^2 + 5$, and $f(-3) = 3(9) + 5 = 32$.

Example 4: an expression as the input

If $f(x + 2) = 3x - 1$ for all $x$, what is $f(5)$?

  1. The input here is $x + 2$, so ask: what $x$ makes $x + 2 = 5$? It is $x = 3$.
  2. Put $x = 3$ into the right side: $3(3) - 1 = 8$. So $f(5) = 8$.
  3. Putting $5$ straight into $3x - 1$ gives $14$, which is $f(7)$, not $f(5)$.

The mistakes that cost points

  • Reading $f(x)$ as multiplication. $f(3)$ is the output for input $3$, not $3f$.
  • Leaving out parentheses for negatives. With $f(x) = x^2$, $f(-3) = (-3)^2 = 9$. Without parentheses you get $-9$.
  • Solving when you should evaluate, or the reverse. "Find $f(19)$" and "$f(a) = 19$" are different questions. Check whether $19$ is the input or the output.
  • Substituting into only part of the rule. For $f(2a)$ with $f(x) = x^2 + 4$, the answer is $(2a)^2 + 4 = 4a^2 + 4$. Writing $2a^2 + 4$ squares only the $a$.
  • Working $f(g(x))$ from the outside in. Always start with the inner function.

  • C$17$

Show solution
Answer: B. $f(4) = 3(4) - 5 = 12 - 5 = 7$. Choice C adds $5$ instead of subtracting it, and choice D solves $f(x) = 4$ instead of finding $f(4)$.

Medium
The function $f$ is defined by $f(x) = \dfrac{x + 9}{x - 3}$. Which of the following values of $x$ is not in the domain of $f$?
  • A$-9$
  • B$-3$
  • C$3$
  • D$9$
Show solution
Answer: C. A fraction is undefined when its denominator is $0$. $x - 3 = 0$ when $x = 3$. At $x = -9$ the numerator is $0$, which is allowed: $f(-9) = 0$.
